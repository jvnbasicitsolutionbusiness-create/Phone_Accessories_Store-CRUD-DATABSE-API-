# StockFlow Frontend + Firebase / Google Sheets Prototype

## Firebase
Configured database URL:
`https://midtermexamproject-default-rtdb.firebaseio.com`

The prototype uses the Firebase Realtime Database REST endpoint. Firebase documents that a Realtime Database URL can be used as a REST endpoint by appending `.json`.

## Google Sheets / Apps Script
Use `google-apps-script.gs`.

Google Sheet tab name: `Users`

Row 1:
`NAME | USERNAME | PASSWORD | AGE | ACCOUNT_S | GMAIL | PHONE NO. | OTP`

Apps Script deployment:
1. Extensions > Apps Script.
2. Paste `google-apps-script.gs`.
3. Deploy > New deployment > Web app.
4. Execute as: Me.
5. Who has access: Anyone.
6. Copy the `/exec` URL into `js/config.js`.
7. Set `ENABLE_GOOGLE_SHEET_SYNC: true`.

## Security warning
This prototype mirrors the requested sheet columns, including PASSWORD. Do not use plaintext passwords in production. The production version should use Firebase Authentication, secure email verification/password reset, Firebase Security Rules, and preferably App Check.

The supplied Firebase rules starter is intentionally closed until Firebase Authentication is connected.
